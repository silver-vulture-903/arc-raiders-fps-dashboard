# ARC Raiders FPS Dashboard — feature reference

ARC Raiders FPS Dashboard focuses on three connected areas: frame pacing records, graphics profiles, comparison notes. Its organization keeps frequently used options close to the context they belong to.

| Section | Description |
|---|---|
| Frame pacing records | Display or performance-related options, with space for configuration and comparison information. |
| Graphics profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Comparison notes | A dedicated section for comparison notes and the configuration details associated with that area. |

The project page follows the same section structure.
